EnvLatch 0.1.0 — UNSIGNED PREVIEW

This build is ad-hoc signed. It has not been signed with an Apple Developer ID
certificate or notarized by Apple. GitHub hosts this file, but macOS Gatekeeper
will not treat it as an identified-developer release.

Install:

1. Double-click "Install EnvLatch.command".
2. If macOS blocks it, open System Settings > Privacy & Security and choose
   Open Anyway only if you downloaded this DMG from:
   https://github.com/Raylinkh/envlatch/releases/tag/v0.1.0
3. The installer places the app in ~/Applications, the CLI at
   ~/.local/bin/envlatch, and the shared agent skill under
   ~/.agents/skills/envlatch.
4. Open ~/Applications/EnvLatch.app. macOS may require Open Anyway once more.
5. Run:
   envlatch doctor
   envlatch help

Before mounting the DMG, verify its adjacent checksum file:

  shasum -a 256 -c EnvLatch-0.1.0-macos-arm64-unsigned.dmg.sha256

EnvLatch never includes API keys in the DMG. Add credentials only through the
installed app's secure field after you have verified the download.

Source, security policy, and build instructions:
https://github.com/Raylinkh/envlatch
