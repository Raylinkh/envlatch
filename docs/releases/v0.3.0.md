# EnvLatch v0.3.0

Status: draft

EnvLatch v0.3.0 adds a native Simplified Chinese interface alongside English.
The app follows the macOS preferred language by default and adds a compact
native Settings window for an explicit language choice and build identity.

## What changes

- The main vault, key and key-group editors, dialogs, validation, recovery
  guidance, status messages, and accessibility labels support Simplified
  Chinese.
- Dynamic counts and user-supplied names remain correctly interpolated in both
  languages.
- **EnvLatch → Settings…** offers System Default, English, and Simplified
  Chinese; changes apply immediately to EnvLatch content.
- Settings shows the exact version/build and identifies the running copy as an
  installed app, development build, or other app bundle.
- The packaged app now verifies that its compiled `zh-Hans` resources are
  present.

## What stays stable

- CLI output and machine-readable `key=value` fields remain English.
- Commands, environment-variable names, provider and API-contract names, URLs,
  and the reusable agent setup prompt are not translated.
- Keychain storage, access control, selection, and process-launch behavior are
  unchanged.

Signed/notarized download checksums and publication receipts will be added only
after the exact release candidate is accepted and published.
